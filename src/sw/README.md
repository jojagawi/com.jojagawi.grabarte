# Service Worker

Fuente del service worker en TypeScript.

## Archivos

- `src/sw/service-worker.ts`: fuente editable.
- `public/service-worker.js`: artefacto generado y servido por Next.js.

## Comandos

```powershell
pnpm run build:sw
pnpm run dev
pnpm run build
```

`build:sw` compila el archivo TypeScript y sobrescribe `public/service-worker.js`.
